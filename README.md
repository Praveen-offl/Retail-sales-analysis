Retail Sales Analysis and Prediction

Objective
The objective of this project is to analyze retail sales data, uncover business insights, visualize trends, and build a machine learning model to predict sales.

Dataset
The dataset contains retail order information including:
- Order Date
- Category
- Region
- Segment
- State
- City
- Sales
- Ship Mode


Tools and Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn


Project Workflow

1. Data Collection
Imported the retail sales dataset using Pandas.

2. Data Cleaning
- Checked missing values
- Processed date columns
- Verified column data types

3. Exploratory Data Analysis (EDA)
Performed analysis using:
- Sales by Category
- Orders by Region
- Sales by Segment
- Monthly Sales Trend
- Correlation Heatmap

4. Data Visualization
Created multiple visualizations to identify:
- Sales trends
- Regional performance
- Customer behavior
- Seasonal patterns

5. Machine Learning
Built a Linear Regression model to predict sales using:
- Category
- Region
- Segment

6. Model Evaluation
Evaluated the model using:
- R2 Score
- Mean Absolute Error
- Actual vs Predicted visualization


Key Insights
- Sales vary significantly across regions.
- Certain product categories generate higher revenue.
- Customer segments influence purchasing behavior.
- Sales show noticeable monthly trends.
- Machine learning successfully predicted sales patterns.


Correlation Heatmap
A correlation heatmap was used to identify relationships between numerical variables and understand patterns within the dataset.-

Conclusion
This project successfully combined Exploratory Data Analysis and Machine Learning techniques to analyze retail sales data and generate meaningful business insights.

The project demonstrates:
- Data preprocessing
- Business analytics
- Data visualization
- Predictive modeling
- Insight generation
